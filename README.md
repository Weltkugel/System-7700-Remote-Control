# System-7700-Remote-Control
ESP8266 based infrared remote control replacement for SHARP RRMCG0182AFSA SC-7700CDHKM2 SC-7700CDEMK2 SC-7700

This is my attempt to emulate the remote control browser based using a Wemos D1 (ESP8266) with an attached IR LED. You will need to enter your Wi-Fi credentials and potentially adjust the GPIO pin. The IR LED is driven via a transistor.
